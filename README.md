# Almost Crack'd

An AI-powered humor web app where users sign in, upload images, get AI-generated captions, and vote them funny or not. The consumer-facing side of a broader humor content platform.

##  Tech Stack
- **Framework:** Next.js 16 (App Router) + React 19
- **Language:** TypeScript
- **Styling:** Tailwind CSS v4
- **Backend & Auth:** Supabase (SSR + JS client) with Google OAuth

##  Features
- Google sign-in with Supabase Auth
- Image upload flow
- AI-generated captions for uploaded images
- "Funny or not" voting to surface the best captions
- Companion app to a separate admin dashboard for content management

##  Related
Part of a larger humor platform. The admin side lives in [humor-project-admin](https://github.com/orkiminy/humor-project-admin).
